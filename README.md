# Fileworks organization profile

This public repository owns the [organization profile](profile/README.md).
It contains presentation content, not shared executable governance or private
project context. Product usage/setup remain in each product's maintained docs.

## Contribute

```console
gh repo clone fileworks/.github organization-profile
cd organization-profile
```

Edit `profile/README.md`, verify its links and public installation instructions,
then open a PR. The `docs-links` workflow validates repository documentation and
agent routes; it must pass before merging. Use [AGENTS.md](AGENTS.md) and
[decisions](docs/decisions.md) for maintenance rules and ownership.

The profile appears on the Fileworks GitHub page after the PR is merged.
Development uses AI assistance; the owner reviews published information.
